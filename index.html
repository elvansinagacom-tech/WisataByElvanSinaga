    Prototipe layanan informasi pariwisata cerdas berbasis AI. Membantu Anda mengeksplorasi destinasi memukau Indonesia.

    Tentang Prototipe Ini

    Aplikasi ini adalah prototipe dari UI/UX, Frontend, dan sistem Chatbot lokal. Data yang digunakan bersumber dari panduan yang ada per Oktober 2026.

    Catatan: Aplikasi ini belum terhubung langsung ke WhatsApp, API AI eksternal, atau database real-time. Fungsi chatbot dijalankan melalui algoritma pencocokan kata kunci (NLP lokal) di dalam browser Anda.
